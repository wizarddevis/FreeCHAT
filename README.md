# FreeChat

FreeChat is a messaging and social media application that allows users to communicate, share videos, and interact with an AI assistant. The app provides a unique blend of chat functionalities and social features, making it a versatile platform for users.

## Features

- **Chat Functionality**: Users can register and chat with others. Unregistered users can be invited via SMS.
- **Payment System**: Users can pay to access chat and video features. 
  - Chat for 24 hours: Pay sh300 to 0784313474.
  - Watch videos for 24 hours: Pay sh400 to 0784313474.
- **Social Media Features**: Users can post videos, like, follow others, and comment on posts.
- **AI Assistant (WIZARD 1)**: An integrated AI feature that helps users with inquiries and provides assistance.

## Getting Started

### Prerequisites

- Node.js
- npm (Node Package Manager)
- TypeScript

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd FreeChat
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the application, run:
```
npm start
```

### Testing

To run the tests, use:
```
npm test
```

## Usage

- Users can register and log in to start chatting.
- Unregistered users can receive SMS invitations to join.
- Users can pay for chat and video viewing as specified.
- Users can post videos and interact with others through likes and comments.
- The AI assistant can be accessed for help and inquiries.
